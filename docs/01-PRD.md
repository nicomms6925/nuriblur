# 01. PRD — NuriBlur

## 제품 한 줄
영상을 넣으면 "지정한 사람·차량만 남기고" 나머지 얼굴과 번호판을 자동 모자이크 처리해 돌려주는 PC 프로그램. 기관 CCTV 열람 제공 업무(개인정보보호법 §35)에 결재·감사 기능을 포함해 납품한다.

## 타깃
- 1차: 공공기관·지자체 CCTV 관제/정보공개 담당 (B2B, 폐쇄망 설치, 결재·감사 로그·보고서 필수)
- 2차: 유튜버·크리에이터 (B2C, 간편 모드·구독)

## 비기능 요구사항
| 항목 | 목표 |
|---|---|
| 성능 | RTX 4060, 1080p: 분석 ≥60 FPS, 렌더링 ≥120 FPS. CPU 8코어: 분석 ≥6 FPS |
| 품질 | 얼굴 누락률 <3%(MVP)→<1%(V1 검수 포함), 번호판 누락률 <5%→<2% |
| 안전 | 식별 신뢰도 낮으면 마스킹 유지, 블러 하한(σ≥15), 픽셀 블록 ≥8px |
| 보안 | 외부 전송 없음, 모델 서명 검증, 워커 127.0.0.1 + 토큰, 감사 로그 append-only |
| 플랫폼 | Windows 10/11 x64 우선, macOS Apple Silicon(V2) |
| 설치 | 단일 설치파일(온라인/오프라인 2종), 모델 번들 |

## 사용자 시나리오
1. **기관 열람 제공**: 접수번호 등록 → 영상 분석 → 청구인(본인) 클릭 지정 → 담당자 검수 → 팀장·부서장 결재 → 보고서 PDF + 출력본 제공 → 90일 후 자동 삭제.
2. **블랙박스 공유**: 상대 차량 번호판만 남기고 제3자 번호판·얼굴 블러.
3. **기업 홍보 영상**: 임직원 3명 참조 사진 등록, 방문객 블러.
4. **유튜버(V2)**: 본인 사진 등록 → 전부 자동.

## 범위 밖
실시간 스트림 처리, 클라우드 처리, 음성 비식별(V3 검토).
