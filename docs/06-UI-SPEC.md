# 06. UI 스펙 (목업 v0.3 기준)

목업 `mockup/nuriblur-mockup.html`을 브라우저에서 열어 6단계를 모두 눌러본 뒤 구현한다. 레이아웃·용어·색을 그대로 따른다.

## 레이아웃 (PySide6)
```
┌ TopBar: 로고 │ 6단계 스테퍼 │ 실행환경 배지(GPU·로컬 처리) ────────────────┐
├ QueuePanel(260) │ StageView(캔버스+트랜스포트) │ SidePanel(320, 단계별) ┤
├ TimelinePanel(160): 트랙 레인 + 룰러 + 플레이헤드 ─────────────────────┤
```
- 메인 윈도우 = `QMainWindow`, 중앙 `QSplitter`(수평) 안에 `QueuePanel | StageView | SidePanel`, 하단 `QDockWidget`(타임라인).
- 캔버스 = `QGraphicsView` + 프레임 `QGraphicsPixmapItem` + 박스 오버레이 `QGraphicsRectItem`(클릭 토글). 프레임은 `GetFrame`으로 480p~1080p 요청.
- 상태 머신 = `app/state/machine.py` (02-ARCHITECTURE의 작업 상태를 그대로).

## 단계별 화면
### 1 입력
- 드롭존(다중), URL 입력(기관 설치본 숨김), 큐 목록(썸네일·파일명·해상도·길이·상태 배지).
- 사이드: 메타(코덱·해상도·FPS·길이·오디오), 검출 대상 체크(얼굴/전신/번호판/간판 V2), 프로파일 세그먼트(GPU 정밀/GPU 빠름/CPU), 예상 시간, **분석 시작**.
### 2 분석 모니터
- 단계 라벨+%, 진행 바, 남은 시간, 5단계 체크(입수/디코딩/검출·추적/임베딩·OCR/트랙 저장), 일시정지·취소.
- 게이지 3개(분석 FPS, GPU %, VRAM), 검출 카운터 3개, 로그 뷰(레벨 색), 캔버스에 라이브 미리보기(2 FPS).
- 렌더링 시 같은 화면 재사용(단계 라벨 "렌더링·인코딩 중", 완료 시 "노출 재검사 통과").
### 3 보호대상 선택
- 캔버스 박스 오버레이: 색=상태, 태그 `F#3 ✓`/`F#12 ?`/`P#4`. 클릭 → 토글(트랙 전 구간).
- 사이드: 안내 문구(기본은 모두 가립니다), 카운터(보호/마스킹/검수), **이 프레임의 트랙** 목록(썸네일·ID·구간·근거·토글), 참조 사진 등록(V1), 번호판 입력(V1), 영역 제외 그리기(V1).
- 범례 표시.
- **(추가)** "보호대상 외 전체 가리기 (사람 전신·차량 전체)" 체크(5단계 내보내기 옵션과 같은 설정), 차량 박스 `V#` 클릭으로 차량 보호(번호판 함께 보호), 하단 "보호대상 확정 · 검수로" 버튼.
- **(추가)** 마스킹 대상 지정 도구: 클릭(주변 자동 탐색) 또는 드래그. 지정 영역은 원본 화면에 주황 "수동" 박스로 표시.
- **(추가) 객체 목록(영상 전체)**: 병합된 트랙과 외형 유사도 0.7 이상 병합 제안을 하나의 객체로 묶어 썸네일·ID·구간·신뢰도로 보여 준다. 여러 개를 골라 마스킹 제외(보호)·객체 아님(가리지 않음, 재검사는 받음)·마스킹으로 일괄 지정. 종류·상태 필터, 정렬, '짧고 흐린 객체 숨기기'(0.5초 미만·신뢰도 0.35 미만, 숨겨도 마스킹). 4단계에서도 연다.
- **(추가)** 관리자 권한 실행 시 끌어다 놓기: OLE 대신 WM_DROPFILES로 받는다(Windows UIPI).
- **(추가)** 재설정: "보호·마스킹 설정 초기화"(규칙 전체 삭제 → 모두 가림, 분석 유지), "처음부터 다시 분석".
- **(추가)** 영상 끌어다 놓기는 창 어디에서나(영상 화면 포함).
### 4 검수
- **(추가)** 재검사 노출: "모두 마스킹하고 다시 내보내기" 한 번으로 노출 전부를 가리고 자동 재내보내기(남으면 최대 3회 반복 후 검수 화면). 노출이 남은 채 "검수 완료 · 내보내기로"를 누르면 처리 방법을 묻는다.
- **(추가)** 병합 제안: 보호대상과 무관한 제안은 "n건 모두 병합"(일괄), 보호 트랙으로 이어지는 제안만 하나씩 확인. 목록은 보호 관련 우선 40건까지.
- 검수 필요 목록: 끊김(병합 버튼), OCR 불일치(보기), 누락 의심(보기). 수동 박스·구간 전신 마스킹 버튼.
- 미리보기 세그먼트: 원본 / 마스킹 결과 / 좌우 비교.
- 타임라인 레인 클릭 → 프레임 이동, 점선 = 끊긴 구간.
### 5 내보내기
- 스타일 세그먼트(픽셀화/블러/단색/세그먼트), 강도·여백 슬라이더(하한 표시), 코덱·품질, 오디오 유지, 메타데이터 제거(기본 on), 감사 로그 저장, 저장 위치, **내보내기 시작**. 완료 후 자동 6단계.
### 6 결재·리포트 (기관 모드)
- 처리 건 정보(접수번호·근거·청구인·담당자/승인자).
- **결재선 설정**: 프리셋(2단/3단/4단) + 결재자 입력 + 저장(관리자 권한). 저장 시 감사 로그.
- 결재 단계 리스트(동적), 결재 의견, **승인(현재 단계 역할·이름 표시)** / **반려(검수로 되돌림)**.
- 출력 제공: PDF 첨부, 해시 기록, 워터마크, 보관 기간, 보고서 PDF 저장, 출력본 제공(최종 승인 후 활성).
- 캔버스에 보고서 미리보기 오버레이(서명란 = 결재 단계 수 + 출력 제공).
- 감사 로그 뷰(append-only).

## 접근성·품질
- 키보드 포커스 링, 색 외에 태그 문자로도 상태 구분(✓ ?), 긴 작업 중 UI 프리즈 금지(모든 RPC는 스레드/async).
- 라이트/다크 테마 자동.
