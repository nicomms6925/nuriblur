# 07. 국내 번호판 검출·OCR 학습 계획

## 한 줄 요약
해외 공개 모델은 국내 번호판을 학습한 적이 없으므로, 검출과 OCR 모두 AI Hub + 현장 CCTV 데이터로 재학습한다.

## 대상 번호판 유형 (모두 학습·평가에 포함)
신형 8자리 흰색(2019~) · 구형 7자리 흰색 · 구형 녹색 · 2단형(화물·구형 승용) · 영업용 노란색(택시·버스·화물) · 전기차 하늘색 · 외교(감청) · 임시 · 건설기계 · 이륜차(소형 2단).

## 데이터
| 출처 | 용도 | 비고 |
|---|---|---|
| AI Hub 자동차 차종·연식·번호판 인식 영상 등 | 1차 학습 | 학습 모델의 영리 판매 허용, 출처 명시 필수, 데이터 재배포 금지 → 가중치만 배포. 데이터셋별 약관 다운로드 시 재확인 |
| PoC 기관 CCTV 2,000장 | 2차 보강 | **비식별 처리 후** 라벨링, 야간·우천·역광·원거리·사선 포함. 수집·보관 동의서 템플릿 필요 |
| 합성 데이터 | 희귀 유형 보강 | 번호판 템플릿 렌더링(폰트: 번호판 전용체 유사) + 배경 합성 + 블러·노이즈·원근 변환 |
| 자체 촬영 | 평가 세트 | 500장, 유형×조건 매트릭스 |

## 검출 모델
- YOLOX-s, 클래스 `face / person / plate` 단일 모델(공동 학습). 입력 1280(장변). 손실 가중치 plate 1.5(소형 객체).
- 증강: 모자이크, 스케일 0.3~1.5, HSV, 모션블러, JPEG 압축, 야간 시뮬레이션.
- 내보내기: ONNX opset 17, fp16, 동적 배치. `models/manifest.json`에 해시·학습 데이터 출처·라이선스 기록.
- 목표: 검출 재현율 ≥98% (IoU 0.5, 평가 세트), 20px 이하 번호판은 "미인식 영역" 처리.

## OCR
- PaddleOCR rec 모델을 한글 사전으로 재학습: 지역/용도 문자(가나다라마거너더러머버서어저고노도로모보소오조구누두루무부수우주하허호바사아자배 등) + 숫자.
- 유형별 정규식 검증: `^\d{2,3}[가-힣]\d{4}$`, 2단형은 상단 지역명 분리 처리. 트랙 상위 5프레임 다수결, 신뢰도 < 0.8이면 `REVIEW`.
- 목표: 완전일치 ≥90%(검수 큐 보조).
