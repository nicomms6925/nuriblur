# 08. 기관 모드 — 결재선 · 감사 로그 · 보고서

## 한 줄 요약
처리 건마다 "청구인 지정 → 담당자 검수 → (기관이 설정한 N단 결재) → 출력 제공 · 보관"이 강제되고, 모든 행위가 해시 체인 감사 로그에 남는다.

## 결재선 설정
- 기관 관리자(role=admin)가 `org_approval_line`에 설정. 프리셋: 2단(담당자 검수→승인자), 3단(담당자 검수→팀장→부서장, 기본), 4단(…→개인정보보호책임자). 단계·역할명·결재자는 자유 편집(최대 6단).
- 처리 건 생성 시 결재선을 `case_file.approval_line_snapshot`에 복사. 이후 설정이 바뀌어도 진행 중인 건은 영향 없음.
- 결재자 부재 시 대결자 지정(V1).

## 결재 흐름
```
REVIEWING(담당자 검수 완료) → PENDING_APPROVAL(step 1) → … → APPROVED → DELIVERED → RETAINED → PURGED
                                     └ REJECTED → REVIEWING (모든 결재 단계 초기화, 사유 필수)
```
- 승인 버튼은 현재 단계 역할·이름을 표시. 마지막 단계 승인 후에만 "출력본 제공" 활성.
- 반려는 어느 단계에서든 가능, 사유 필수, 담당자에게 알림.
- 사용자 식별: Windows 로그인 계정 + 앱 내 PIN(V1: AD/LDAP 연동 옵션).

## 감사 로그
- 이벤트: 작업 생성, 분석 완료, 보호대상 지정/해제, 병합, 수동 박스, 검수 완료, 결재선 변경, 승인/반려(의견 포함), 렌더링 완료(재검사 결과), 보고서 생성, 출력본 제공(해시), 보관 만료 삭제.
- 해시 체인(`prev_hash → hash`), DB 트리거로 수정·삭제 금지, 월 1회 체인 검증 리포트.
- 내보내기: JSON/CSV, 보고서 PDF 부록.

## 결과 보고서 (PDF)
항목: 보고서 번호, 접수번호, 처리 근거(법령 조항), 청구인·보호대상 근거, 마스킹 통계(얼굴/전신/번호판 트랙 수, 스타일·강도), 검수 처리 내역, 노출 재검사 결과(0건), 출력 파일명·SHA-256·메타데이터 제거 여부, 결재 서명란(단계 수만큼)+출력 제공, 감사 로그 요약.
- 생성: `worker/orgmode/report.py` (reportlab 또는 HTML→PDF), 한글 폰트 임베드.

## 출력 제공 옵션
- 열람 전용 워터마크(접수번호·일시, 반투명), 출력본 해시 기록, 보관 기간(기본 90일, 만료 시 출력본·프로젝트 삭제 / 감사 로그·PDF 보존).

## 폐쇄망 설치본
- yt-dlp·업데이트 체크·모델 다운로드 모두 제거, 모델 번들 포함(약 1.5GB), 라이선스 = 기관 사이트 키 또는 USB 동글.
- GS인증·보안 취약점 점검 대비: 설치 경로 권한, 로그 민감정보 미기록, 임시 파일 즉시 삭제.
